Lo mínimo para compilar y ejecutar los ejemplos de juguete de la guía. Verificado con .NET 9.

Los ejemplos de juguete viven en el proyecto ejemplos/, junto a este documento. Referencia el proyecto Puppeteer y no necesita nada más. Cada ejemplo es autocontenido:

bashcd ejemplos
dotnet run              # todos
dotnet run -- cap2.1    # contador            dotnet run -- cap5   # control de flujo
dotnet run -- cap2.2    # torniquete          dotnet run -- cap6   # dominio C#
dotnet run -- cap3      # DSL a fondo         dotnet run -- cap7   # replay
dotnet run -- cap4      # parametros          dotnet run -- cap8   # salida
dotnet run -- cap15     # modificar una app viva (receta del Cap. 15)

El “andamiaje” es una sola utilidad que crea el actor listo para usar (en el proyecto, además, silencia la línea de arranque que el framework imprime para que la salida quede limpia):

C#public static ActorV2 NuevoActor(string nombre, Assembly dominio)
{
    var actor = new ActorV2(nombre, dominio);
    actor.ConfigureStorage(DatabaseType.IN_MEMORY, nombre);
    return actor;
}

El código completo de cada ejemplo está en el proyecto ejemplos/ (una carpeta por capítulo); aquí mostramos solo los fragmentos que ilustran cada idea. Los ejemplos de juguete cubren las Partes I y III (mecánica del actor, DSL, parámetros, guardas, dominio, replay, salida y la receta de modificar una app). Los fragmentos marcados real a lo largo de la guía provienen de la aplicación Velada y no forman parte de este proyecto ejecutable; la Parte II se ilustra con esos fragmentos reales por depender de transportes y varios nodos.
