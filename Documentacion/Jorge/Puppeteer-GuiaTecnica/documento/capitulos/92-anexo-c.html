upgrade('seed') { saldo = 100; }        // una sola vez por actor

Control de flujo y guarda

DSLif (aforo.Cabe(@n)) { aforo.Tomar(@n); }        // una decision = un comando
foreach (x in @nums) { total = total + x; }     // no hay for; solo foreach
Check(aforo.Cabe(@n)) Error 'sin cupo';         // guarda (con PerformCheckThenCommand)

Parámetros (lado C#)

C#.WithParameters(p =>
{
    p["sku", typeof(string)] = sku;          // entrada @sku
    p["dias", typeof(int[])] = items;         // coleccion
    p["dia", typeof(Enum)] = "Monday";         // enum por NOMBRE
    p[Parameter.Out,  "turno", typeof(int)] = default;    // leer de vuelta
    p[Parameter.Eval, "id", typeof(int)] = "lastId + 1"; // derivado del estado
})

Formato de la llamada Perform

  • Encadena en el orden: actor.Using(script) → .WithParameters(...) → .PerformCommand() / .PerformQuery() / .PerformCheckThenCommand().
  • Para un cuerpo de varias líneas, usa una cadena literal (@"...") con una sentencia por línea.
  • Un parámetro por línea en .WithParameters, en el mismo orden en que aparecen en el script.
  • Pasa valores como @params; nunca los interpoles en el texto del script (rompe la densidad del diario).
